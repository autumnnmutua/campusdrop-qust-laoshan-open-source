# 配送工作台

市场使用服务端楼栋、大小件、配送方式筛选和游标分页，每页12条。接单、退单及生成批次后同步刷新。

授权任务支持“全部订单、进行中、待学生签收、已完成/已取消”分类。分类在服务端执行并继续应用管理员scope；选择分类时会清空冲突的具体状态筛选和当前页勾选。

批量取件信息与批次创建均可一键选择当前页，单次最多20单。翻页、筛选和刷新会清空选择；批量取件信息30秒后自动隐藏，查看与复制操作写入脱敏审计。

取件失败或配送异常先打开说明表单，确认后才推进状态；取消草稿不会写入订单。退回接单市场必须填写独立理由，学生与下一位接单人可查看此前各轮理由。

交接已支持驳回及申请人修改，账号已支持恢复码找回，超级管理员可查看脱敏错误监控。详细机制、权限及边界见 [可靠性说明](reliability.md)。

仍未提供短信验证、自动客服、真实收费与资金结算。公网连接故障可重试和定位，但无法保证永不发生。
