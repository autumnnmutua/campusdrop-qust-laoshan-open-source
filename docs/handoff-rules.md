# 包裹交接与异常处理规则（接口规范）

本规则用于当前应用内支付流程。管理员必须按实际情况填写，不得以软件确认代替真实交接。没有真实扣款或退款，也未接入站点系统验证实物。

1. 未取件时不能继续接单，应说明原因并退回接单市场，学生可看到退单原因，其他配送员可以接单。
2. 已取件后，当前配送员负责妥善保管包裹。不得随意放在楼道、室外或交给身份不明人员；不得以点击退单的方式消除保管责任。
3. 无法继续配送时先标记“配送异常”，填写问题并联系学生；将包裹归还原取件站点，确认站点工作人员接收，记录具体存放位置、外包装是否完整以及交接情况。遗失、损坏或站点拒收时保持异常，不得提交虚假归还。
4. 提交归还申请后，系统暂停该订单配送推进。另一位有订单权限的超级/区域/楼栋管理员必须核对实际包裹、位置及站点接收情况，再点击核验。申请人不能核验自己，普通配送员没有核验权限。
5. 核验后可退回市场重新接单；学生也可取消并模拟退款。重新接单的配送员必须到原站点重新取件，不得假定包裹仍在上一配送员手中。
6. 包裹仍由配送员持有、交接尚未核验时，系统拒绝退回市场、取消退款及旧版直接删除。原配送账号有未完成任务时不能直接停用，应先处理配送或交接。
7. 学生取消、模拟退款、隐藏记录是不同操作。取消后保留订单和退款进度；隐藏仅移除学生列表，不抹去审计和付款记录。当前可退金额为实际模拟配送费及补款，未付款为零，已送达不在该自助取消范围。
8. 发生争议、遗失、损坏、错误填写或无法联系时，由负责该区域的管理员处理。当前还没有完整客服工单和交接驳回/修改流程，正式运营前需补齐运营联系人与售后规则；不能承诺系统已自动鉴定责任或赔付。
