# 文字跳动效果设计说明

## 设计原则

文字跳动适合用在“值得注意的时刻”，但不应该让学生阅读的正文一直在动。所以这一版只在三类地方使用：

1. **品牌时刻**：第一眼看到的标题，用来建立记忆点；
2. **状态变化**：系统告诉学生“有事发生了”的那一刻，用来吸引注意；
3. **轻松场景**：加载中、走错页面、小游戏这类不需要认真阅读的地方，用来缓和等待和出错的感受。

订单详情、费用、规则说明这类需要仔细阅读的文字一律不跳，避免干扰阅读，也照顾晕动敏感的用户。

## 四种跳法

| 跳法 | 效果 | 时长与节奏 | 适合 |
| --- | --- | --- | --- |
| 下落（drop） | 每个字从上方落下，触底后轻轻回弹一次 | 每个字 0.75 秒，字与字间隔 60 毫秒 | 品牌标题，页面打开时播放一次 |
| 弹跳（pop） | 每个字依次跳起再落回 | 每个字 0.6 秒，字与字间隔 45 毫秒 | 状态刚刚变化、操作成功 |
| 波浪（wave） | 文字像波浪一样轮流轻轻起伏，持续进行 | 一轮 1.8 秒，字与字间隔 110 毫秒 | 加载中、404 页这类短文字 |
| 悬停（hover） | 鼠标经过某个字，这个字跳起并稍微倾斜、变成品牌蓝 | 0.28 秒弹性回落 | 桌面端的标题和标语，手机上不触发 |

## 已经加入的位置

| 位置 | 跳法 | 说明 |
| --- | --- | --- |
| 首页主标题“校园快递配送” | 下落 + 悬停 | 打开首页时逐字落下；之后在电脑上用鼠标划过，每个字会跳起来 |
| 首页“当前订单”状态徽章 | 弹跳 | 只在页面打开期间状态发生变化时跳一次（例如从“配送中”变为“已送到寝室”），首次打开不跳 |
| 订单详情页状态徽章 | 弹跳 | 同上，配合实时刷新和状态提示一起出现 |
| 订单完成提示“订单已完成” | 弹跳 | 确认收货后的成功时刻 |
| 注册成功标题 | 弹跳 | 创建账号后的成功时刻 |
| 打赏成功提示 | 弹跳 | 打赏完成后的感谢语 |
| 页面加载中“正在加载…” | 波浪 | 切换页面、网络稍慢时出现 |
| 404 页标题 | 波浪 | 让走错页面不那么生硬，下方还有接包裹小游戏 |
| 小游戏结算“新纪录！ / 游戏结束” | 弹跳 | 每局结束时 |
| 左侧栏标语“让期待，近一点。” | 悬停 | 电脑端鼠标划过时跳动 |
| 公告横幅的级别标签（通知 / 提醒 / 暂停服务） | 弹跳 | 公告出现时跳一次，提醒学生有新消息 |
| 新解锁的徽章名称 | 弹跳 | 进入“我的寝室”看到新徽章时，配合彩带一起出现 |

管理端（配送工作台、数据看板等）不使用文字跳动，保持工作界面安静。

## 开关与无障碍

- 学生可以在顶部“氛围”菜单里关闭“文字跳动”，也可以用 Ctrl+K 快捷搜索“跳动”切换。设置只保存在本机浏览器。
- 系统开启“减少动态效果”时，所有跳动自动停止。
- 读屏软件只朗读一次完整文字，不会把每个字拆开来读。
- 动画只改变位置和透明度，不改变排版，所以跳动时周围的内容不会跟着挪动。

## 以后想加到别的地方

在页面里把要跳动的文字换成组件即可，例如：

```tsx
import { BounceText } from './bounce-text';

<h2><BounceText text="双十一快递高峰" variant="drop" /></h2>                    {/* 打开时落下 */}
<span><BounceText text={状态文字} trigger={状态} playOnMount={false} /></span>  {/* 状态变化时跳一次 */}
<p><BounceText text="正在排队…" variant="wave" /></p>                          {/* 持续波浪 */}
```

节奏和幅度集中在 `src/client/extras.css` 的“文字跳动”一节（`bt-drop`、`bt-pop`、`bt-wave` 三组动画），调整那里会统一影响全站。

## 可选的扩展方向（尚未实现）

如果甲方希望效果更明显，可以考虑在节日期间（例如新年、毕业季）把首页标题换成节日文案并使用下落效果。这需要甲方提供文案和起止日期，同样可以直接复用这个组件实现，不需要新增依赖。
